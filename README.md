# 紙上小日子 · Paper Games

數獨、踩地雷、Zip 連線與 Patches 拼區。米白紙感、墨綠配色，適合手機直向遊玩的單人益智小遊戲。

## 使用方式

以瀏覽器開啟index.html即可遊玩；手機建議使用部署後的網站網址。沒有帳號、後端或外部題庫，題目由瀏覽器即時隨機產生。

## 遊戲

- **數獨**：第0–3級；筆記、清除、復原與可切換的重複提示。
- **踩地雷**：第0–3級；開格／插旗，第一次開格及周圍八格安全。
- **Zip**：依數字順序連線，走滿所有格子；支援拖曳、逐格操作、退一步與提示。
- **Patches**：依面積與形狀線索劃分矩形，填滿棋盤；支援提示、復原與清空。

Zip與Patches有第0–4級。第4級「挑戰」維持6×6，從候選題中篩選搜尋分支較多、已驗證唯一解的題目。這是程式難度代理指標，不是正式技巧評級；篩選未完成時可換題重試。

## 進度與資料

切換遊戲時，當次棋盤暫留在記憶體；重新整理或關閉網頁後清除。沒有雲端同步、固定關卡或不重複保證，不使用外部AI API或下載題庫。

## 部署

此專案是單一HTML檔案，無需建置。將儲存庫根目錄交由靜態網站服務提供即可，首頁為index.html。

## 開發與驗證

原生HTML、CSS、JavaScript。出題保留時間／搜尋上限，只有完成搜尋並確認唯一解的候選才可採用。已進行原四級一致性、獨立解題器、提示／復原／通關及手機寬度版面檢查；各裝置的觸控感受與出題耗時仍可能不同。

玩法參考：[Zip](https://www.linkedin.com/help/linkedin/answer/a7445030) 與 [Patches](https://www.linkedin.com/help/linkedin/answer/a10314037) 的公開玩法說明。此專案自行實作畫面、遊戲邏輯與隨機出題。
